# Sales & Revenue Analysis Dashboard

## Project Overview
This project is a Power BI dashboard built using the Superstore dataset to analyze sales, revenue, profit, and business performance.

## Features
- Total Sales KPI
- Total Profit KPI
- Total Orders
- Total Quantity
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Interactive Filters (Year, Category, Segment, Region)

## Tools Used
- Power BI Desktop
- Microsoft Excel / CSV

## Dataset
Superstore Sales Dataset
